# Pemetaan Sumber Materi

Build ini disusun dari dua kumpulan materi presentasi yang diberikan pengguna.

## Pemrograman Web I

13 PPTX: pengenalan Laravel/route/view, HTML, tabel, form/list, CSS, Bootstrap, navbar/card/grid, database, MVC/CRUD, template, tugas dan quiz.

## Pemrograman Web II

11 PPTX: setup project klinik, database, authentication, CRUD dokter, validation, update/delete/pagination, template dashboard, CRUD administrasi, relasi, formatting, dan evaluasi/proyek akhir.

Materi yang tumpang tindih digabung dengan prinsip: Web I = pengenalan konsep, Web II = penerapan pada aplikasi.
